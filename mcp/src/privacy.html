Privacy policy — Word Counter MCP

Last updated: August 24, 2026

This policy covers the MCP server at wordcount-mcp.mhsenkow.workers.dev and the related demo page. The full editor at ibm.io/wordcount runs entirely in your browser and is described separately below.

MCP server

  • Text is sent to the server only when you (or an AI assistant on your behalf) call a counting tool.
  • Text is analyzed in memory to produce word, character, sentence, paragraph, and reading-time counts.
  • Text is not stored, logged, or used for training.
  • No accounts are required.

Full editor (ibm.io/wordcount)

  • Your draft and settings are stored locally in your browser via localStorage.
  • Nothing is sent to a server unless you explicitly use a browser feature that requires network access (e.g. optional web fonts).
